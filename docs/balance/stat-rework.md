## 1. 문제

- 유저 빌드가 **통무 / 통지**로 쏠리고, **무지**와 **올라운더**는 선택받지 못함.
- 원인: 통솔이 병력 상한과 징병량을 둘 다 독점. 병력은 **화력이면서 동시에 체력**이라 격차가 크게 벌어짐.
  - 전투력 ∝ 병력^0.7, 체력 ∝ 병력 → 교전 가치 대략 **병력^1.7**에 비례.
  - 현행 통무(7,000) 대 무지(3,000): 화력 1.81배 × 체력 2.33배 ≈ **약 4배**.

## 2. 코드에서 확인한 현행 규칙 (시즌 8)

| 항목 | 실제 코드 | 위치 |
|---|---|---|
| 최대 병력 | `통솔 × 100` (+ 특성 마성의 장수 +1,000) | `rules.js` `troopsMax`, `RULES.troopsPerLea` |
| 징병 1회 | `통솔 × 22~27 + 공적 × 0.1` × 치안 × (1 + 세력·개인 특성·수도 보정) | `rules.js` `draftGain`, `engine.js` `runDraft` |
| 부대 전투력 | `4500 × (병력/4500)^0.7 × (0.5 + 병종능력치/120)`. 보병=통솔, 기병=무력, 궁병=지력 | `rules.js` `unitPower`, `RULES.troopCurve` |
| 무력 공통 보너스 | 무력 1당 +0.15%, 공격·수비 모두 | `RULES.warPer1`, `warBonus` |
| 책략·돌격 | 능력치 70 이상 + 상대보다 높아야 발동. 확률 능력치/2000, 병력 배율 `min(1,(병력/5000)^0.3)` | `RULES.scheme`, `RULES.charge`, `troopScale` |
| 받는 피해 감소 | 보통 합의 `hitDef`에만 `(1 - min(0.9, 방어도감소 + 철벽))`. **공격 쪽·야전엔 감소 경로 없음** | `fightRounds` |
| `defensePower` | 받는 피해 감소가 아니라 **수비 쪽이 주는 반격 피해** | `rules.js` `defensePower` |
| 내정 담당 | 농업·상업·기술=지력, 축성=무력, 치안=통솔 | `DOMESTIC` |
| 병종 변경 | 다른 병종으로 징병하면 **있던 병력 전부 흩어짐** | `engine.js` `runDraft` |
| 경험치 비용 | 능력치 1 올리는 데 `35 + 능력치 × 1.45` (시즌 8) | `RULES.expNeedBase/Per`, `expNeed` |
| 생성 | 총 170, 한 항목 30~70, 최대 120 | `ROLL`, `RULES.statMax` |

> 참고: 현행 구조에선 상한과 징병이 모두 통솔에 비례 → **0에서 상한까지 채우는 턴 수는 통솔과 무관하게 약 4.1턴**.

## 3. 논의 흐름과 결론

### 3.1 검토 후 기각/보류한 안
| 안 | 결과 |
|---|---|
| 상한 = 최고 능력치 × 100 | 몰빵 강제. 기각 |
| **상한·징병 둘 다 순수 평균** (V1a) | 시뮬 결과 **무지 메타**가 됨 (무력 공통화력 + 돌격 + 책략을 다 가짐). 기각 |
| 가중 평균 α (GPT 원안) | 가능하나 아래 V1이 더 깔끔 |
| 상한만 바꾸고 징병은 통솔 그대로 | 무지가 상한을 못 채움 (4턴 → 7~8턴). 반드시 같이 바꿔야 함 |

### 3.2 현재 유력안: **V1**
```text
병력 상한 = 평균(통·무·지) × 100
징병 1회  = (평균 + 통솔) × 12~14 (무작위) + 공적 × 0.1   (치안·특성 보정은 기존대로)
```
- 통솔의 새 정체성 = **빨리 채우는 장수 (지속력)**. 상한은 같아도 재출진 속도가 다름.
- 120/120/120 기준 징병 3,120 ≈ 현행 2,940 → 후반 템포 거의 유지.
- 통솔 비중을 더 원하면 `(평균 + 통솔 × 1.5) × 11~13`.

| 빌드 | 상한 | 징병 1회 | 채우는 턴 (현행 4.1) |
|---|---:|---:|---:|
| 통무 70/70/30 | 5,667 | 1,647 | 3.4 |
| 올라 57/57/56 | 5,667 | 1,478 | 3.8 |
| 무지 30/70/70 | 5,667 | 1,127 | 5.0 |

### 3.3 통솔 받는 피해 감소 (β) — **보류**
```text
받는피해 = 원래피해 ÷ (1 + 통솔 × β)     // β=0.0015면 무력 공통 보너스와 대칭
```
- 시뮬 결과 V1에 얹으면 통솔 쪽으로 다시 기움 (무지 소모전 0.91 → 0.80). V1의 징병 속도만으로 통솔 메리트 충분.
- 나중에 넣는다면: `hitDef`·`hitAtt` 둘 다(야전 포함)에서 **기존 방어도 감소와 따로 곱할 것** (0.9 상한과 엉키지 않게). `defensePower`에 곱하면 안 됨.
- 보조 후보: 책략·돌격 받는 피해 감소 (특성 '침착' `calm`과 같은 자리) — 무지의 무기를 통솔이 막는 구도.

### 3.4 올라운더 (전투 외 이점)
- **이미 있는 장점**: 경험치 비용이 능력치에 비례해 오르므로, 같은 총 경험치를 고르게 쓰면 합계가 더 높음.
  - 총 경험치 18,000: 통무(몰아줌) 120/120/30 = 270 vs 올라(균등) 97/97/97 = **291**.
  - 단, 각 능력치에 경험치를 똑같이 주면 특화형도 낮은 능력치가 싸게 올라 차이 거의 없음 (293 vs 291) → 장점은 "고르게 쓰는 행동"에서 나옴.
  - 현행에선 합계가 전투에 거의 안 쓰이지만, **V1(평균 상한)에선 합계 = 병력**이라 이 장점이 실전 가치로 바뀜.
- 추가 혜택 후보 (V1 적용 후 부족할 때만):
  1. **병종 전환 시 병력 유지** (현행은 전부 흩어짐) — 상성 맞춰 갈아타기. 1순위.
  2. 모든 내정 +10~15%.
  3. 서로 다른 행동을 골고루 하면 공적 보너스.
  4. 수련 경험치를 가장 낮은 능력치로 (균형 유지용 보조).
  - 피할 것: 계략 성공률 보너스(지력 영역), 책략·돌격 70 조건 완화(무지 강화).
- **균형도 판정은 변동계수 사용** (표준편차 그대로는 능력치 규모에 따라 커짐):
  ```text
  변동계수 = 표준편차 ÷ 평균
  균형도   = clamp(1 - 변동계수 ÷ 0.3, 0, 1)
  혜택     = 최대 혜택 × 균형도          // 화면엔 "균형도 %"로 표시
  ```
  | 능력치 | 변동계수 | 균형도 |
  |---|---:|---:|
  | 57/57/56 | 0.01 | 97% |
  | 60/60/50 | 0.08 | 74% |
  | 100/100/80 | 0.10 | 66% |
  | 60/70/40 | 0.22 | 27% |
  | 70/70/30 | 0.33 | 0% |

## 4. 시뮬레이션 결과

`rules.js`의 실제 `fightRounds`를 vm으로 불러와 실행 (시즌 8 값, 게임 코드 수정 없음).
- **야전 교환비**: 상한 가득 찬 상태로 야전 1회, 상대 손실 ÷ 내 손실.
- **소모전 처치비**: 40턴 동안 "상한 80% 이상이면 출진, 아니면 징병". 처치 ÷ 피처치.
- 숫자는 상대 3빌드 대비 기하평균, 1.00 초과면 유리. 표기: `야전 / 소모전`.

> 무지 소모전 0.77은 통솔 30 고정이라는 극단 가정. 실제로는 징병마다 통솔 경험치가 쌓여 더 나음.

### 해석
1. 현행은 무지가 소모전에서 통무에게 0.49로 두 배 넘게 밀림.
2. 순수 평균(V1a)은 무지 메타로 넘어감.
3. **V1은 역할 분리가 깔끔**: 무지 = 한 번 싸움에 강함(야전), 통솔 빌드 = 긴 전쟁에 강함(소모전). 후반엔 거의 대칭.
4. β는 통솔 쪽으로 다시 기울게 해서 보류.
5. V1에선 올라운더의 경험치 효율이 병력으로 전환돼 소모전 0.71 → 0.92.

### 부수 발견
- **통지가 통무보다 항상 약함** (1:1 약 0.88). 무력 공통 화력(+0.15%/pt) 때문. 통솔 공식과 별개 문제 → 지력 보정이 필요하면 따로 논의.
- **올라운더는 어느 안에서도 1:1 약 0.8~0.9.** 책략·돌격·단기접전이 모두 70 이상 조건. 시뮬레이터는 병종 전환·내정의 가치를 못 잼.

### 시뮬레이터 한계
- 1:1만. 다인전·수성(방어도)·수비대 없음.
- 특성·보물·장비·세력 특성·공적·경험치 성장 = 0.
- 징병 비용(금·군량)·치안 감소 미반영.
- 병종: 각 빌드의 최고 능력치 병종 후보들을 상대와 고르게 조합해 평균.

## 6. 시뮬레이터 사용법

```bash
# 저장소 루트에서 (Node.js 필요, 의존성 없음)
node tools/balance-sim/sim.js                  # 전체 (약 3~4분)
node tools/balance-sim/sim.js early            # 초기 빌드만
node tools/balance-sim/sim.js late_exp V0,V1   # 같은 경험치 후반 빌드, 현행·V1만
```
- 안(variant) 정의: `sim.js`의 `VARIANTS` (cap / draft / beta). 새 안은 여기 추가.
- 빌드 묶음: `BUILDS` (early / late / late_exp).
- β는 `fightRounds`의 `dLoss/aLoss` 한 줄을 문자열 치환해서 끼워 넣음. `rules.js` 해당 줄이 바뀌면 시뮬레이터가 에러를 내니 패치 지점만 맞춰주면 됨.
